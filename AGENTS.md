# Project instructions

- Write the simplest working implementation that meets the stated requirements.
- Use existing functions directly where they are needed. Skip helpers that only forward a call.
- Add validation, fallback values, guards, retries, or locks only when explicitly requested or required for the requested behavior to work.
- Keep edits within the requested scope.
- Use single quotes for string literals whenever the language syntax allows it.
- Leave a blank line between consecutive control-flow statements at the same indentation level, such as `if` statements, `try`/`except` statements, and `for` loops. Keep clauses of the same statement together.
